# S.O.Z.
S.O.S. (Sistema Operacional do Zero)
## Como Executar o S.O.Z.

### 1. Usando o QEMU (Ideal para uso rápido / terminal / Android via Termux) para o Android
```
bash qemu-system-i386 -fda jcos.img
```
### 2. Usando o VirtualBox (Para ambiente de desktop)

- Crie uma nova Máquina Virtual (Tipo: Other, Versão: Other/Unknown).
- Configure o drive de disquete (Floppy Disk) apontando para o arquivo jcos.img.
- Inicie a VM.
