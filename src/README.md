# Código-Fonte (src)  

Esta pasta contém o código-fonte principal do **S.O.Z.** em **C** e **Assembly x86**:

* **`kernel.c`: Núcleo do sistema operacional e loop principal.
* **`keyboard.c`: Driver de captura e mapeamento do teclado.
* **`screen.c`: Gerenciador de exibição e controle do buffer de vídeo VGA.
* **`shell.c`: Interpretador de comandos do sistema.
